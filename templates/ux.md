# 🎨 交互与布局规格 (ux.md)

> **L2 表现层（行为半边）** · 唯一写者 **uiux agent** · 读者 **dev（按此 1:1 实现交互与布局，⛔ 不自行改结构）、qa（据此验交互五态）**。
> 📐 **写什么**：前端形态与页面清单、每页 ASCII 布局原型、组件清单、交互五态矩阵、可交互元素（testid）、断点布局变化、跨页流转。
> 🚫 **不写什么**：业务规则（→ `prd.md`）、**色值 / 字体 / 圆角 / 阴影 / 间距 / 样式实现 / 组件长相**（→ `design.md`）、组件库家族与主题入口（→ `project.md` §一.1）、接口参数（→ `api.md`）、字段类型（→ `data.md`）、实测结果（→ `gates.md`）。
> 🚫 **pm 禁读本文件**：L1 意图层不得被 L2 反推（需求侧结论只写 `prd.md`）。

**判据一句话**：**换一套皮肤仍然成立** → 写这里；**换皮肤就会变** → 写 `design.md`。同一事实只落一处，⛔ 两处都不记。

> 视觉数值、组件长相、图标、配色与明暗方案全部在 `.cc_code/active/design.md`（唯一视觉事实源）；前端形态的十种分类与选型规则唯一出处 = 插件 `skills/cc-code/references/frontend-forms.md`；视觉判词与规则号唯一出处 = 插件 `skills/cc-code/references/ui-gates.md`。本文件只留指针。

### ⛔ 写入纪律（active = 最新 + 最完整 + 最纯净）

| 纪律 | 说明 |
| :--- | :--- |
| **页面章节按页序追加** | 新页面一律追加在**最后一个页面章之后、`跨页流转` 之前**，页章号顺延；⛔ **不在中间插页**（前插会让 `U` 与 `V` 的编号整体漂移）。删页时该页章整章原文搬 `backup/retired/ux.md`，后续页章号**不回填** |
| **元素与判定项就地插入** | 新元素插进**该页的「可交互元素清单」**并续编**元素序号**；新判定项插进**该页的「交互五态矩阵」**并续编 `U` 号（每页 U 水位只增不回退）；已有元素 / 判定项只**就地改写那一行**，⛔ 不重排、不复用编号 |
| **就地收敛** | 增量变更直接改写对应小节的那几行，⛔ 禁新开 `## 增量 F-n` 章节、⛔ 禁整份重写。同一个元素在本文件永远只有一处描述 |
| **过程外置** | 需求清单 / 原型草稿 / 裁决过程 ⛔ 不落盘（对话内即用即弃，留痕 = `backup/change-log.md` 一行）；本文件只留「现在的交互与布局是什么」 |
| **台账外置** | 每次增量在 `backup/change-log.md` 追加**一行**（F 号 / 日期 / 层 / 文件 / 模块 / 改了什么 / 裁决 / 详情链接，格式见 `Agent.md` 归档规范）；本文件内不留任何台账 / 附录 / 历史痕迹 |
| **过期搬走不删** | 作废的页面 / 元素 / 判定项：原文整段 append 到 `backup/retired/ux.md`（带日期 + 来源小节 + 退役原因），再从本文件移除。⛔ 不留删除线尸体、⛔ 不直接删内容 |

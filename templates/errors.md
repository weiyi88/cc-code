## ⛔ 入库判据（唯一标准）

**每条记录的「预防规则」必须能写成「以后禁止 …」或「以后必须 …」的句式。写不出这句话，就不属于本文件。**

| 装什么 | 不装什么 | 该去哪 |
| :--- | :--- | :--- |
| 根因级、不可重犯的**规则** | 待修的 bug 清单 | `gates.md` |
| | 下一步要做什么 | `status.md` |
| | 一次性的调试过程 | 哪都不去，丢弃 |

> 判据的意义：`errors.md` 是**越积越值钱的永久资产**，而 bug 清单是一轮即焚的临时物。混装会让这份资产被垃圾淹没，最终没人再读它。

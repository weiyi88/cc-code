| **做完即搬走** | 做完的坐标 / 已解的卡点 / 已完成的下一步：`backup/milestone-log.md` 记一行，原文需留档的整段搬 `backup/retired/status.md`，再从本文件移除 |
| **长度恒定** | 本文件永远一屏以内（坐标几行 + 卡点 + 下一步）。⛔ 不追加历史、不留做完的条目 |
| **业务语言** | 卡点与下一步用业务语言写，⛔ 不写技术细节（技术细节在 agent 报告与 `gates.md` / `bugs.md` 里） |
